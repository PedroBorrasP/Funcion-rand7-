# Funcion-rand7-
La idea era utilizar una función existente que genera números enteros aleatorios del 1 al 5 para confeccionar otra que genere números enteros aleatorios del 1 al 7.

El archivo "rand7.mlx" contiene el código asociado a la función.
El archivo "Prueba.mlx" contiene el código asociado a una prueba con la representación en un histograma para comprobar que la función devuelve números enteros del 1 al 7 distribuidos de manera uniforme.
